# EssentialsX Configurator

## Made with <3 for the Minecraft Community

### Created by StoneyG59

## Overview
EssentialsX Configurator is a powerful and intuitive Minecraft server plugin designed to revolutionize how server administrators manage their EssentialsX configurations. Born from the passion of the Minecraft community, this plugin bridges the gap between complex configuration management and user-friendly interaction.

## Purpose
In the dynamic world of Minecraft server management, flexibility is key. The EssentialsX Configurator empowers server administrators to:
- Modify configuration settings in real-time
- Eliminate the need for server restarts
- Maintain granular control over configuration changes
- Instantly view and update plugin settings

## Key Features
- **Live Configuration Management**: Edit settings without interrupting server gameplay
- **Secure Permission System**: Granular access controls for different administrative levels
- **Intuitive In-Game Interface**: Manage configurations directly from the Minecraft client
- **Robust Error Handling**: Comprehensive validation and error reporting
- **Performance Optimized**: Lightweight plugin with minimal server overhead

## Commands
- `/essxconfig get <key>`: Retrieve a specific configuration value
- `/essxconfig set <key> <value>`: Update a configuration value
- `/essxconfig list`: Display available configuration keys
- `/essxconfig reload`: Reload EssentialsX configuration

## Permissions
- `essxconfig.view`: View configuration values
- `essxconfig.edit`: Modify configuration values
- `essxconfig.reload`: Reload entire configuration

## Installation Requirements
- **Minecraft Version**: Paper 1.19.4+ (1.19.x, 1.20.x, 1.21.x)
- **Dependencies**: EssentialsX 2.21+

### Version Compatibility Details
- **Fully Supported Minecraft Versions**:
  - 1.19.4
  - 1.20.4
  - 1.20.6
  - 1.21.1

- **Compatibility Strategy**:
  Our plugin is designed with a forward and backward compatibility approach. We ensure smooth operation across multiple Minecraft versions by:
  1. Using compatible Paper API versions
  2. Implementing version-agnostic configuration management
  3. Maintaining consistent plugin behavior across supported versions

- **Version Detection**:
  The plugin automatically detects and adapts to the server's Minecraft version, providing a seamless experience for server administrators.

## Installation
1. Download the latest plugin JAR
2. Place the JAR in your server's `plugins` directory
3. Restart or reload your Minecraft server
